# Project instructions

## Superpowers workflow

This project uses the `freebuff-superpowers` skill pack. Before responding to or
acting on any non-trivial request, read:

- `~/.agents/skills/using-superpowers/SKILL.md`
  (Windows: `%USERPROFILE%\.agents\skills\using-superpowers\SKILL.md`)

Follow its routing table. When it selects a workflow skill, open that skill's
`SKILL.md` from the same `skills` directory with the file-reading tool and follow
it; skills are files, not tools. A matching workflow is a mandate, not a
suggestion. The user can also force a skill with `/skill:name`.

Keep the process proportionate: for a one-line fix with an obvious cause, skip
brainstorming and the design doc, but still verify the result.

Re-read this section after a context compaction. If the pack is not present on
this machine, continue with normal practice and say so rather than inventing
skill contents.
